# Receptionist client demonstration

A standalone scripted demonstration of booking, confirmed-number SMS, owner handoff, and Spanish conversations. Includes an automatic guided tour with bundled synthetic narration, visible matching text, and mobile layouts.

All business details, callers, bookings, texts and handoffs are simulated. No live integrations, customer-data collection, secrets, or backend access are included. This showcase is not the production receptionist.

Open index.html directly or serve this folder with a static web server. Click **Start narrated demo** for audio.

Narration generated locally using [Kokoro](https://github.com/hexgrad/kokoro). Audio playback is bundled and does not require API keys or an account.
