# Bay Answer interactive preview

A standalone scripted demonstration of booking, confirmed-number SMS, owner handoff, and Spanish conversations. Includes an automatic guided tour with bundled synthetic narration, visible matching text, and mobile layouts.

Bay Answer is built in Tampa by Sino Technology Solutions. The browser walkthrough uses fictional Bayside Auto Detail data: its sample hours, prices, and free ceramic consultation are unchanged. Preview bookings, texts, and handoffs are simulated. The live-call link opens the separate real phone experience; the pilot link opens an email draft. No call or email is sent by viewing this page.

Open index.html directly or serve this folder with a static web server. Click **Start narrated demo** for audio.

Narration generated locally using [Kokoro](https://github.com/hexgrad/kokoro). Audio playback is bundled and does not require API keys or an account.

## Share image and address

`assets/share-preview.svg` is the editable code-native brand card. `assets/share-preview.png` is its 1200×900 raster export. Open Graph and Twitter metadata currently use the existing GitHub Pages address; update the page/image URLs together if the published address changes.

For a custom domain, use an address you control, configure it in the chosen host, apply that host’s DNS records, and verify HTTPS after DNS resolves. Keep the domain’s page URL and social image URL consistent. Hosting/domain changes are separate from the local preview files.
